# **App Name**: QuizWise

## Core Features:

- Quiz Generation from Text: Users can paste text or upload documents to generate quizzes. The AI tool analyzes the content and generates questions.
- Quiz Generation from URL: Users can input a URL, and the AI tool will generate a quiz based on the content of the webpage.
- Interactive Quiz Interface: Presents generated quizzes in a user-friendly interface with question display and immediate answer feedback.
- Difficulty Level Selection: Allows users to choose the difficulty level (easy, medium, hard) for quiz generation.
- Shareable Quiz Links: Each quiz gets a unique URL for easy sharing and tracking of responses.
- AI Powered Feedback: AI tool analyzes answers, cross-references to source material, and provides personalized explanations for incorrect answers and suggests study areas. 

## Style Guidelines:

- Primary color: Teal (#008080) to evoke knowledge and trust.
- Background color: Light teal (#E0F8F8) for a calm, focused environment.
- Accent color: Mustard (#E6B800) to highlight key interactive elements and calls to action.
- Body and headline font: 'Inter' sans-serif for a modern, objective look. 
- Simple, clear icons to represent actions and feedback within the quiz interface.
- Clean, single-column layout for easy content consumption.
- Subtle transitions and animations for feedback to provide a more engaging experience.
